## display模式转换
转换为区块元素 `display: block;`

block, inline, inline-block

解决行内块元素中间空白缝隙问题：
将父元素字号改为0，适合**对间距要求不高**的情况

解决图片底部空白缝隙问题：
- 转换为块级元素 `display: block;`
- 改成不是基线对齐 `vertical-align: middle;`

## 弹性布局
核心：
1. 父控子
2. 主轴和交叉轴

父盒子设置`display: flex;`可以让子盒子按**主轴**排列，子盒子可以伸缩

### 对齐方式
justify-content： 定义**主轴**上的对齐方式

| 属性值        | 说明                      |
| ------------- | ------------------------- |
| flex-start    | 左对齐                    |
| flex-end      | 右对齐                    |
| center        | 居中对齐                  |
| space-between | 两端对齐                  |
| space-around  | 两侧间隔相等，`-A--B--C-` |
| space-evenly  | 间隔均匀分布              |

align-items： 定义**交叉轴**上的对齐方式（单行）

| 属性值     | 说明                         |
| ---------- | ---------------------------- |
| flex-start | 起点对齐                     |
| flex-end   | 终点对齐                     |
| center     | 居中对齐                     |
| stretch    | 拉伸填充，需子元素无固定高度 |

align-content：定义**交叉轴**上的对齐方式（多行），属性值与justify-content相同

### flex-direction
定义主轴方向

属性值： row, **column**

### flex-wrap
定义是否换行

属性值： nowrap, wrap

### gap
写到父元素，设置间距

行间距20px，列间距30px： `gap: 20px 30px;`

### flex
写到子元素，优先级比width和height高

属性简写：
- flex-grow 放大比例
- flex-shrink 缩小比例
- flex-basis 初始大小

## 定位布局
> 子绝父相：子元素绝对定位，父元素相对定位

| 定位类型          | 脱离文档流 | 定位基准           |
| ----------------- | ---------- | ------------------ |
| 相对定位 relative | 否         | 自身正常位置       |
| 绝对定位 absolute | 是         | 最近定位祖先或视口 |
| 固定定位 fixed    | 是         | 视口               |
| 粘性定位 sticky   | 否         | 视口或滚动祖先     |
| 不定位 static     | 否         | 默认文档流         |

偏移属性：top、bottom、left、right

优先级：top覆盖bottom, left覆盖right

粘性定位需指定至少一个方位名词

行内元素加了定位后可以直接给宽度和高度

### 层叠顺序 z-index
语法：`z-index: 数值;`

数值越大，层级越高

默认auto，后出现的元素覆盖前者

仅对定位元素有效

## 网格布局
父盒子设置`display: grid;`

单行用flex，多行或响应式用grid

### 创建网格轨道
定义三列，每列宽度为100px：`grid-template-columns: 100px 100px 100px;`

定义三行，每行高度为100px：`grid-template-rows: 100px 100px 100px;`

重复3次： `repeat(3, 1fr)`

自动填充，最小值为100px：`repeat(auto-fill, minmax(100px, 1fr))`


### 对齐方式
| 属性            | 说明             |
| --------------- | ---------------- |
| justify-content | 列轨道对齐方式   |
| align-content   | 行轨道对齐方式   |
| justify-items   | 项目水平对齐方式 |
| align-items     | 项目垂直对齐方式 |

### 跨单元格
跨行 grid-row，跨列 grid-column，写到子元素上

语法1：`grid-column: 1 / 3;`

语法2：`grid-column: 1 / span 2;`

### 填充方式
grid-auto-flow 子元素填充方式

属性值：row先行后列，column先列后行

图片缩放：
```css
object-fit: cover;
object-position: center;
```

## 多列布局
将一个元素的内容分成指定数量的列

属性：
- column-count 列数
- column-gap 间距
- column-rule 分隔线

解决底部元素被切断问题：
子元素设置`break-inside: avoid-column;`

## 鼠标样式
可点击： `cursor: pointer;`

不可选中： `cursor: not-allowed;`

CSS属性书写顺序建议：布局、盒模型、视觉、交互、其他
