## 2D变换
transform
- 平移 translate()
- 旋转 rotate()
- 缩放 scale()
- 倾斜 skew()

复合写法，从右往左执行： `transform: translate() rotate();`

平移的单位是百分比时，相对元素自身尺寸：
```css
top: 50%;
left: 50%;
translate(-50%, -50%);
```

旋转参数单位：deg（度）, turn（圈数）

transform-origin设置旋转中心点

行内元素无法直接旋转，需要转换

## 3D变换
左手法则

旋转：rotateX(), rotateY()

位移：translateZ(), translate3d(x, y, z)

透视效果：
- 给父元素添加`perspective: 1000px;`
- 给子元素添加`transform: perspective(1000px) rotateX(45deg);`

隐藏背面：`backface-visibility: hidden;`

开启3D空间：给父元素添加`transform-style: preserve-3d;`

## 动画
1. 定义动画 动画名称、关键帧（from、to或百分比）
```css
@keyframes move {
  from {
    transform: translateX(0);
  }
  to {
    transform: translateX(100px);
  }
}
```
2. 使用动画：`animation: 动画名称 动画时长;`

完整写法：`animation: 动画名称 动画时长 速度曲线 延迟时间 播放次数 播放方向 执行完毕状态`
- 无限循环：infinite
- 播放方向交替：alternate

暂停动画：单独写`animation-play-state: paused;`

逐帧动画：速度曲线设为`steps(步数)`，配合精灵图
